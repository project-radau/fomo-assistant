# FomoAssistant

A small Rust price tracker for selected Websites.

FomoAssistant monitors product prices and notifies you when a product drops below a configured threshold.

## Features

* Track products
* Store price history
* Configure a target price
* Check current prices
* Get notified when a price drops below the target
